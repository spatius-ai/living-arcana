# Contributing

Open an issue describing the problem or proposed improvement. For a pull request, branch from `main`, keep the change focused, and include steps to verify the behavior.

Use Node.js 24 and pnpm 10.33.0. Run `pnpm install --frozen-lockfile`, `pnpm test` and `pnpm build` before submitting. Add tests when behavior changes.

Never commit API keys, local environment files, customer data or account-specific deployment configuration. Include only code and assets you have permission to redistribute. Contributions are provided under the MIT license.
